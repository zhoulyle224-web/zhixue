# 提示词版本管理

## 命名

文件采用“用途-版本”语义，正文首行记录版本：

```text
<!-- prompt: system, version: 2026-09-14.v1, owner: 项目组 -->
```

## 变更流程

1. 修改前记录基线用例与当前通过率。
2. 小版本只改措辞；权限、拒答、脱敏规则变更使用大版本。
3. 每次变更至少回归 `tests/local-api.test.mjs` 与 `scripts/verify-skills.cjs`。
4. 生产环境按“提示词版本 + 模型版本 + 知识库版本”组成发布号。
5. 不把真实姓名、手机号、学号、密钥或原始作答写入提示词样例。

## 发布门禁

- 提示注入测试必须 100% 拦截。
- 无资料问题不得生成事实性结论。
- 输出引用覆盖率必须达到 100%。
- 涉及发布、分层、课程修改的任务必须存在人工确认点。
