通用规则：
- 调数据库前必须验证角色、班级上下文和字段白名单。
- 只读查询优先于任何写入；当前 MVP 不允许智能体直接写成绩、任务或课程内容。

```json

  "tool": "",
  "allowed": true,
  "arguments": {},
  "reason": "",
  "fallback": ""
}
```
