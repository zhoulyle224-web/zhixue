在模型推理、检索、日志、缓存和导出前执行数据脱敏。

直接标识符：
- 姓名、学号、手机号、邮箱、证件号、家庭住址、微信号、QQ 号替换为 `[已脱敏]`。
- 面向班级分析时使用匿名编号，例如 `S-7F21A9`，同一班级内保持稳定映射。

准标识符：
- 出生日期只保留年龄段。
- 班级、专业、课程可保留；与姓名组合后必须剥离姓名。
- IP 地址只保留网段，例如 `10.***.***.21`。

敏感推断：
- 不根据出勤、成绩或答疑记录推断家庭、心理、健康、经济等属性。
- 不生成可能造成污名化的学生标签，使用“当前该知识点需补强”等任务性描述。

输出示例：
```json
{
  "student_ref": "S-7F21A9",
  "course": "人工智能导论",
  "knowledge_point": "模型评估",
  "mastery": 54,
  "evidence_count": 30,
  "pii_removed": ["姓名", "学号", "手机号"]
}
```

脱敏后若仍可通过组合字段识别个人，应降低粒度或阻止导出。
