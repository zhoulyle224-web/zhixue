# PPT 大纲

## 1. 封面

- 标题：智学双擎
- 副标题：课后即时答疑与学情智能研判
- 关键词：本地部署、有据回答、教师确认

## 2. 真实痛点

- 教师每班学情整理 2 至 4 小时。
- 学生课后等待时间长。
- 重复问题占用教师大量精力。
- 单点 AI 工具无法形成教学闭环。

## 3. 场景选择

- 核心场景一：课后即时答疑。
- 核心场景二：学情智能研判。
- 选择理由、使用频次和成功标准。

## 4. 用户任务

- 教师三步：选班级、确认数据、生成研判。
- 学生三步：选课程、提问、查看引用。
- 左右并排展示角色入口。

## 5. 总体架构

- 感知、规划、记忆、工具、执行、评估、安全七层。
- 标注本地 SQLite、离线模型、断网降级和人工接管。

## 6. 核心功能

- 数据质检。
- 班级与个体画像。
- 薄弱知识点和分层。
- 有引用课程答疑。
- 高频问题与 FAQ。
- 脱敏导出。

## 7. Skill 设计

- 五个标准 Skill。
- 输入、输出、异常和人工确认。
- Skill Registry 统一注册。

## 8. OpenClaw 与 AI Coding

- Agent、Workflow、Tool、Memory、Guardrails。
- 统一错误码、结构化日志和版本管理。
- 平台异常时回到本地规则 Skill。

## 9. 一键部署

- Windows 脚本。
- Linux 脚本。
- Docker Compose。
- 内网、无外网和本地模型。

## 10. 数据安全

- 角色权限矩阵。
- PII 脱敏。
- 导出水印。
- 审计日志。
- 提示注入和越权防护。

## 11. 异常与降级

- 数据、操作、断网、模型、工具。
- 降级顺序：在线模型、本地模型、规则 Skill、模板、人工。
- 展示错误码和用户提示。

## 12. 测试与评估

- 26 项 Skill 契约测试。
- 9 项本地 API 与页面集成测试。
- 引用覆盖、工具成功率、响应时延和教师采纳率。

## 13. 落地价值

- 教师：减少重复劳动，研判依据统一。
- 学生：即时获得有依据的个性化支持。
- 管理：本地部署、数据可控、审计可查。

## 14. 演示与团队

- 3 分钟真实系统演示。
- 团队分工。
- 当前完成度与下一步试点计划。
- 结尾一句话：让每一次提问成为教学进化的起点。

## 附录

- 完整评分自评。
- SQLite 数据规模。
- 代码结构。
- OpenClaw 配置摘录。
- 测试输出。
