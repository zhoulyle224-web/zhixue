## 3. 回归测试

每次版本发布必须执行：

1. `npm test`。
2. 三个主流浏览器各打开一次首页、教师端和学生端。
3. 随机选择 10 个班级，比对 SQL 与界面中的均分、及格率、样本量。
4. 使用 2 个无依据问题确认 100% 转人工。
5. 使用学生身份尝试导出教师报告，确认 403。
6. 停止本地 API，确认前端仍可用同源快照完成基本演示。

## 4. 上线门禁

| 门禁 | 阈值 |
|---|---:|
| Skill 契约测试 | 100% |
| 集成测试 | 100% |

| 越权导出漏拦 | 0 |
| 数据库静态暴露 | 0 |
| 教师试点采纳率 | 不低于 70% |
