# 智学双擎公网部署方案

## 目标

公开用户只需访问 HTTPS 地址，无需下载 ZIP、安装 Node.js 或运行批处理文件。首页、登录、教师端、学生端和全部 `/api` 接口由同一个 Node Web Service 提供。

## 数据隔离

- 浏览器首次登录生成 `sbx_` 开头的随机沙箱编号。
- 服务端把沙箱编号绑定到 HttpOnly Session Cookie，并使用独立 SQLite 文件。
- 同一浏览器切换教师、学生身份时复用该沙箱，可体验答疑、回复、任务和反馈闭环。
- 不同浏览器默认进入不同沙箱，运行数据相互不可见。
- 沙箱默认 24 小时过期，空闲数据库连接默认 15 分钟关闭。
- 最多保留 1000 个沙箱；空库约 220 KB，达到容量上限时拒绝创建新空间，避免 1 GB 磁盘被无限占用。

所有数据均为匿名合成演示数据，不接入真实学校统一身份或真实学生数据。

## Render Blueprint

仓库根目录的 `render.yaml` 定义：

- 新加坡区域的 Docker Web Service；
- `0.5c-512mb` 单实例；
- `/api/health` 健康检查；
- 1 GB 持久磁盘，挂载到 `/var/data`；
- HTTPS Cookie、可信反向代理和 24 小时沙箱期限；
- GitHub 检查通过后自动部署。

创建 Blueprint 后，Render 会要求确认付费计算实例和持久磁盘。未完成确认前不会产生正式服务。

## 必需环境变量

| 变量 | 生产值 | 说明 |
| --- | --- | --- |
| `NODE_ENV` | `production` | 启用生产模式 |
| `HOST` | `0.0.0.0` | 接收平台反向代理流量 |
| `PORT` | 平台注入 | 服务监听端口 |
| `ZHIXUE_DATA_DIR` | `/var/data` | 持久沙箱和审计目录 |
| `ZHIXUE_COOKIE_SECURE` | `1` | Cookie 仅通过 HTTPS 发送 |
| `ZHIXUE_TRUST_PROXY` | `1` | 正确识别代理后的 HTTPS Origin |
| `ZHIXUE_SANDBOX_TTL_HOURS` | `24` | 演示空间保留时间 |
| `ZHIXUE_SANDBOX_IDLE_MINUTES` | `15` | 空闲数据库连接关闭时间 |
| `ZHIXUE_MAX_SANDBOXES` | `1000` | 1 GB 磁盘的容量保护上限 |

## 上线验收

1. `GET /api/health` 返回 `mode: public-sandbox`、`database: isolated-sqlite`。
2. 教师账号和学生账号均能通过 HTTPS 登录。
3. 登录响应包含 `Secure`、`HttpOnly`、`SameSite=Strict` Cookie。
4. 同一浏览器中的学生提问能进入教师待办。
5. 第二个无痕浏览器看不到第一个浏览器的运行记录。
6. 服务重新部署或重启后，未过期沙箱仍能恢复。
7. 直接访问 `/data/runtime/`、`/var/data/` 或 SQLite 文件均返回 404。
8. 完整产品测试、Skill 测试、静态检查和公开安全检查全部通过。

## GitHub Pages 处理

GitHub Pages 仅保留宣传预览，不承担登录和数据功能。完整服务上线后，应将首页主要按钮和对外分享链接指向 Node Web Service 地址。
