# 智学双擎参赛交付总览

## 一句话

智学双擎把学生有据答疑与教师学情研判连接成“提问—证据—研判—任务—反馈”的本地可追溯闭环。

## 两个核心场景

1. 学生课后即时答疑：当前课程证据检索、引用回答、资料不足转教师。
2. 教师学情智能研判：真实文件质检、固定研判、3/5/2 分层、任务发布与反馈回流。

## 启动

```bash
node server/local-api.mjs --port 8080
```

访问 `http://127.0.0.1:8080`。Windows 可双击 `deploy-and-open.bat`。

演示账号：`teacher2026 / demo123`、`student2026 / demo123`，均为合成演示身份。

## 核心链路

```text
学生问题 → 当前课程引用 / 教师待办
匿名文件 → 质检 → confirm → analysis run
analysis run → 教师草案 → 发布 → 学生完成 → 教师反馈
```
