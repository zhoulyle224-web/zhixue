# 智学双擎最终部署手册

## 1. 范围与数据

本手册对应本地 Node 正式版。提交包只含匿名合成 baseline 和测试 fixtures；首次写操作会在 `data/runtime/<environment>/` 自动创建运行库。公开静态版是受限展示版，不提供正式身份、AI 密钥配置、写操作或受控导出。

发布 ZIP 的最低要求：Windows 10/11、现代 Chrome/Edge、约 500 MB 可用空间；包内自带 Node.js，不需要外网、`npm install` 或管理员权限。仅源码开发环境要求 Node.js 22.13+。

## 2. 已验证主路径

在源码根目录执行：

```bash
node server/local-api.mjs --host 127.0.0.1 --port 8080
```

打开 `http://127.0.0.1:8080`，健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8080/api/health
```

停止服务使用当前终端的 `Ctrl+C`。不要用模糊进程名批量结束 Node 进程。

## 3. Windows 一键启动

双击 `deploy-and-open.bat` 或 `一键部署并打开.bat`。脚本执行以下步骤：

1. 优先检查并使用包内 `runtime/node.exe`，源码目录缺少该文件时才回退到系统 Node.js；
2. 在 8080～8090 中选择空闲端口，或复用已通过健康检查的实例；
3. 启动本地服务并等待 `/api/health`；
4. 写入仅供本机停止定位的 `data/runtime/server.json`；
5. 打开浏览器。

请先完整解压 ZIP，不要直接在压缩包预览窗口中双击。发布包中的 `.bat` 已固定为 Windows CRLF 换行；缺少启动脚本、内置运行时或数据库时，窗口会暂停并显示可操作的错误信息，而不是瞬间关闭。

命令行前台路径：

```powershell
.\scripts\start-zhixue.ps1 -Port 8080
```

启动失败会给出运行包不完整、端口占用或数据库不可读等明确错误，不会杀死无关进程。

## 7. 登录、CSRF 与恢复

合成演示账号：教师 `teacher2026`、学生 `student2026`，密码均为 `demo123`。

服务端通过 HttpOnly Cookie 保存 opaque Session；CSRF 明文只在登录或 `/api/auth/me` 响应中交给当前页面，数据库只保存哈希。页面重载或服务重启后，只要 remember Session 有效，`/api/auth/me` 会轮换新 CSRF，旧 token 立即失效。

## 8. 备份与升级

`data/zhixue_demo.sqlite` 是只读合成 baseline；业务写入位于 `data/runtime/<environment>/`。通过 `ZHIXUE_ENVIRONMENT=demo|test|production` 选择环境（默认 demo）。正式提交包不会包含 runtime、Session、API Key、AI 运行记录、audit 或日志。

本地备份脚本：

```powershell
.\scripts\backup-local.ps1
```

升级前停止服务并单独备份 runtime。不要用 baseline 覆盖 runtime，也不要把开发 runtime 放入提交包。

## 9. 正式接口与导出

正式导出只接受：

```text
POST /api/export
```

学生身份完全由 Session actor 推导；`offeringId` 仅作为请求范围并再次验证 enrollment。教师范围通过 context 与授权关系验证。JSON、CSV、Excel 兼容 XML（`.xls`）由服务端生成；打印格式是 HTML 打印页，由浏览器另存 PDF。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| `node:sqlite` 不存在 | Node 低于 22.13，升级后重试 |
| `EADDRINUSE` | 选择其他端口，不结束未知进程 |
| 登录后写请求 403 CSRF | 刷新页面触发 `/api/auth/me` 轮换；Session 无效则重新登录 |
| 导出 403 | 检查当前 actor 的角色、context 或 enrollment，不修改客户端身份字段绕过 |
| 打印页未弹出 | 使用正常 Chrome/Edge 检查弹窗策略；不要改成静态文件回退 |
| 断网 | 本地规则 Skill 与 SQLite 主流程仍可运行 |
| `/data/*.sqlite` 404 | 正常安全行为，数据库不会静态暴露 |
