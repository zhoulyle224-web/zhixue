# 智学双擎参赛优化方案（最终交付版）

## 定位

产品定位：校园学情研判与个性化学习智能体。

只展示两个核心场景：

1. 学生课后即时答疑：课程证据、引用回答、资料不足转教师。
2. 教师学情智能研判：导入质检、固定研判、分层任务、完成反馈。

身份、授权、导出、异常与部署作为支撑能力，不包装成第三个场景。

## 技术与平台表述

- 参照帝王蟹 Skill 规范设计输入、输出、异常和人工确认；不声称当前实时调用。
- OpenClaw 只提供语义兼容配置映射；不声称当前实时 runtime。
- AI Coding 用于开发和测试辅助，不是运行时能力。
- 公网模型不是验收主链路必需项。
- PDF 是打印 HTML 后由浏览器另存；Excel 是 SpreadsheetML `.xls`。

## 数据与安全

- 数据、账号、课程资料和 fixtures 均为匿名合成内容。
- Session actor 是身份真相；对象范围由服务端再次授权。
- baseline 只读，runtime 独立；最终包排除 runtime、Session、audit、日志、密钥与 `.env`。
- 导出严格审计失败时不生成文件、不回退静态样例。
