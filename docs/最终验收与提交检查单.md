# 最终验收与提交检查单

状态只使用 `ready`、`blocked`、`not_ready`、`not_required`。当前结论：`M7 not ready for submission`。

## BLOCKING

- `blocked`：M6 必需 manual 尚有 8 项未通过。
- `not_ready`：最终视频二进制不存在，无法全片检查。
- `not_ready`：最终 `.pptx` 不存在，无法逐页与元数据检查。
- `blocked`：最终视频与 PPT 不存在时，官方交付齐全性不能成立。
- `ready`：源码、baseline、启动入口、README、部署手册、测试摘要与 M7 文档已进入 staging。
- `ready`：自动扫描未发现已知组织名称、域名、真实 secret、runtime DB、Session、audit 或日志。
- `ready`：clean staging Node 冒烟通过。

## IMPORTANT

- `not_ready`：Linux 原生环境未复现。
- `not_ready`：Docker daemon 未复现。
- `blocked`：Print HTML 需正常 Chrome/Edge 人工复核。
- `not_ready`：视频录制后需回填真实时间码。
- `not_ready`：PPT 生成后需回填最终页码。
