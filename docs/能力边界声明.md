## 安全边界

- Session actor 是身份真相；客户端 role、studentId、studentContext、context 只能作为请求参数并由服务端复核。
- 写操作要求当前 CSRF；Session 恢复会轮换 token，旧 token 失效。
- baseline 只读，runtime 独立；最终提交包不含 runtime、Session、audit、日志、密钥或 `.env`。
- 教师建议、任务与导出均保留人工确认和权限边界。
- 模型/服务/审计失败时不能伪造成功；正式导出失败不返回文件。
