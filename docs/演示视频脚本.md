# 智学双擎最终演示视频脚本

状态：`not_ready`。本文件是录制脚本，不等于最终视频二进制。

## 录制口径

| 项目 | 口径 |
|---|---|
| 目标时长 | 4:30 ± 15 秒（内部目标，不是官方强制） |
| 分辨率 | 1920×1080 |
| 真实操作占比 | 70% 以上 |
| 核心场景 | 两个核心场景：学生课后即时答疑、教师学情智能研判 |
| 数据 | final release 中的匿名合成 fixture |
| M3 分层 | `publishable-ai201.csv` 的 3/5/2 |
| 测试事实 | M6 final run `20260917T161508Z_943a95e`：175/175、Skill 26/26、E2E 10/10 |

不展示真实个人、组织标识、密钥、Cookie、CSRF、文件选择器本机路径或浏览器无关标签页。

## 0:00–0:20 项目定位

画面：从 final release 启动首页，展示教师与学生两个角色入口。

旁白：

> 智学双擎聚焦两个高频教学场景：学生课后获得有课程依据的答疑，教师把匿名学习数据转成可确认、可发布、可复盘的教学任务。系统本地优先，智能体给建议，关键动作由教师确认。

现场证据：首页两个入口；不使用 PPT 动画替代页面。

## 0:20–1:05 M1 学生有据答疑

操作：

1. 登录 `student2026`，选择当前已选课程；
2. 提问课程内问题并展开引用；
3. 切换到不匹配的课程或提出资料不足问题；
4. 展示 `pending_teacher`，不说“已回答”。

旁白：

> 学生身份和选课范围来自服务端 Session。回答只能引用当前课程知识包；没有依据时不猜答，而是形成教师待办。

技术证据：M1-T01～T20；M6-E2E-02。

## 1:05–1:30 M1 教师待办与课程隔离

操作：

1. 教师端打开对应 context 待办；
2. 回复刚才的问题；
3. 学生端刷新历史，显示同一问题的教师回复；
4. 简短指出另一课程 context 看不到该待办。

旁白：

> 待办、回复和课程隔离都持久化到 runtime SQLite；服务重启后仍可恢复。

人工注意：严格双浏览器/Profile 的 M6 项仍为 blocked，录制前必须用正常 Chrome/Edge 两个独立 Profile 补验。

## 1:30–2:20 M2 真导入与研判

操作：

1. 教师进入数据导入页；
2. 真实选择 final release 的 `tests/fixtures/m3/publishable-ai201.csv`；
3. 展示逐行质检、确认批次；
4. 点击研判，展示 analysisRunId、班级概览、知识点、3/5/2 分层、建议与 evidence；
5. 刷新页面，恢复同一 completed analysis，而不是重新生成。

旁白：

> 页面读取的是刚上传并确认的匿名合成文件。每次研判固定 batch、analysisRunId 和 evidence；刷新或重启只恢复既有结果，不创建新的分析。

技术证据：M2/M2.5 tests；M6-E2E-01；M6-FIX-04/05。

## 2:20–3:05 M3 教学任务闭环

操作：

1. 从当前 analysis run 建立任务草案；
2. 修改巩固组说明并发布；
3. 学生端读取 active task、完成并提交反馈；
4. 教师端查看完成数与反馈摘要；
5. 如录制环境允许，展示撤回后 active 消失、history 保留。

旁白：

> 任务来源固定到研判版本。教师确认后才发布；完成与反馈回流到教师端。撤回和被新版本替代是两个不同终态，历史记录不会被删除。

技术证据：M3-T01～T28、M3-V01/V02；M6-E2E-04/05。

## 3:05–3:35 M4 权限

操作：

1. 学生账号尝试打开教师页，被引导回学生端；
2. 在 DevTools 发起学生请求教师 report export；
3. 展示服务端 403；
4. 教师退出后返回受保护页，显示需重新登录。

旁白：

> 角色和对象范围由 Session actor 决定，客户端 role、context 或 studentId 不能成为身份真相。写请求还必须携带当前 CSRF。

人工注意：双 Profile、DevTools 越权和 localStorage 篡改的完整人工项仍为 blocked；录制不能把未做步骤剪成已通过。

## 3:35–4:05 M5 受控导出

操作：

1. 教师生成 JSON 或 CSV 正式文件，展示水印与脱敏字段；
2. 学生生成本人全部授权课程 learning-record；
3. 模拟严格审计失败，展示明确错误且无下载；
4. 说明 Excel 是 SpreadsheetML `.xls`；打印格式是 HTML 打印页由浏览器另存 PDF。

旁白：

> 正式导出先鉴权、后白名单组装、脱敏、水印和严格审计。审计失败时不返回文件，也不回退到静态样例。

技术证据：M5-T01～T44、M6-FIX-01～03、M6-E2E-08/09。

## 4:05–4:20 异常不泄漏

画面：停止 Node 或使用测试注入触发审计失败，页面显示“本次未生成文件”；快速展示 `/data/zhixue_demo.sqlite` 返回 404。

旁白：

> 服务或审计异常时失败关闭，runtime、baseline 与审计文件均不通过静态路径暴露。

## 4:20–4:30 总结

旁白：

> 智学双擎把有据答疑、真实研判、教师确认、个性化任务和反馈复盘连成一条可追溯闭环。当前提交使用匿名合成数据，不代表真实试点。

画面：回到首页，停留 2 秒。
